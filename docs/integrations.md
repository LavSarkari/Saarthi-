# Integrations

## Firebase
- **Firestore**: Used for real-time data persistence.
- **Auth**: Used for Google Sign-in and user identity management.

## Google Workspace
- **Google Calendar API**: Used to read/write events. Handled primarily on the client-side via OAuth tokens obtained during the login flow.

## Google Gemini
- **Gemini 2.5 Flash**: Used for text processing and reasoning.
- **Gemini Vision**: Used for image/document OCR and structuring.
- **Gemini Live API**: Used for real-time WebSockets-based voice assistance in the Assistant Panel.

## Telegram
- Allows the application to push critical alerts to a user's Telegram account via a bot webhook.
